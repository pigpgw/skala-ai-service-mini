# Runbook: 커넥션 풀 고갈(Connection Pool Exhausted) 대응 절차

1. get_monitoring_status로 풀 사용률과 대기 중인 요청 수를 확인한다.
2. 풀 최대 크기(max_connections)와 실제 동시 사용량을 비교해 설정 부족인지 누수인지 구분한다.
3. 반환되지 않는 커넥션이 있는지 애플리케이션 로그와 스레드 덤프에서 확인한다.
4. 즉시 조치로 풀 크기를 임시 상향하고, 장기 연결을 잡는 코드 경로에 타임아웃을 건다.
5. 정상화 후 커넥션 반환 누락 지점을 수정하고 풀 사용률 알림 임계값을 다시 정한다.
